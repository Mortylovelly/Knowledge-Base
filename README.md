# Minecraft Mods Knowledge Base

Центральная база знаний по Minecraft-модам Mortylovelly. Здесь хранятся инструкции совместной разработки, технические сведения, команды, конфигурации, баги, решения, ссылки на коммиты и результаты сборок.

## С чего начать
**Открой [START_HERE.md](START_HERE.md).** Это главный вход в базу и инструкция для новых чатов.

## Как читать документацию мода

1. Открой `projects/<название>/PROJECT.md`.
2. Для хронологии открой `projects/<название>/updates/`.
3. Записи читаются по возрастанию номера: `001`, `002`, `003` и так далее.
4. Последняя запись не заменяет предыдущие — она дополняет историю.

## Главное
Эта база хранит знания и историю. Реальный код находится в репозитории самого мода. Перед изменениями всегда проверять исходный репозиторий, ветку и Actions.
