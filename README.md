# Minecraft Mods Knowledge Base

Центральная база знаний по Minecraft-модам Mortylovelly. Здесь хранятся инструкции совместной разработки, технические сведения, команды, конфигурации, баги, решения, ссылки на коммиты и результаты сборок.

## С чего начать
**Открой [START_HERE.md](START_HERE.md).** Это главный вход в базу.

## Текущий стандарт разработки

**Minecraft Java Edition 1.20.1 + Fabric + Java 17.** Другие версии не использовать, пока владелец сам явно не разрешит переход. Если у старого мода есть несколько версий/веток и нужная неясна — обязательно спросить до правок.

## Карта репозитория

```text
Knowledge-Base/

├── shared/                    # Общие справочники Minecraft/Fabric
├── templates/                 # Шаблоны паспортов и updates
└── archive/                   # Экспорты чатов, игровые логи и конфиги
```

## Как читать документацию мода

1. Открой `projects/<название>/PROJECT.md`.
2. Для хронологии открой `projects/<название>/updates/`.
3. Записи читаются по возрастанию номера: `001`, `002`, `003` и так далее.
4. Последняя запись не заменяет предыдущие — она дополняет историю.

## Главное
Эта база хранит знания и историю. Реальный код находится в репозитории самого мода. Перед изменениями всегда проверять исходный репозиторий, подтверждённую ветку и Actions.
