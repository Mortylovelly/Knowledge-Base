## Запрос владельца

Сохранять логи, собранные панелью, в отдельной папке внутри игрового каталога Minecraft и добавить кнопку в log panel, которая копирует все сохранённые логи в буфер обмена.

## Что реализовано в исходниках

### 1. Постоянный архив на клиенте

Новый класс: `src/main/java/com/mortylovelly/minecraftai/client/AiLogFile.java`. Каталог относительно game directory (обычно `.minecraft`): `logs/minecraft-ai-agent/`.

Файлы: `latest.log` (текущий), `latest.log.1` (предыдущий), `latest.log.2` (самый старый) и `.legacy-imported` (маркер миграции).

В архив попадают серверные Log4j events, доставленные клиенту через log bridge, и локальные диагностические сообщения AI Agent, направленные через `AiLogClient`. Сетевые пачки записываются одной файловой операцией. Формат текстовый: дата/время, уровень, logger, маркер CUSTOM и текст; многострочные сообщения сохраняются отдельными строками.

Каждый файл ограничен 4 MiB. При переполнении `latest.log` перемещается в `.1`, `.1` — в `.2`, прежний `.2` удаляется. Максимальный сохраняемый объём — около 12 MiB. Перед записью маскируются распространённые шаблоны API keys и tokens.

### 2. Импорт прежнего локального журнала

Раньше `AiAgentLog` отдельно писал небольшой файл `config/minecraft_ai_agent.log` с ротацией `.old`; он не содержал полный поток панели. При первом запуске нового кода прежние `config/minecraft_ai_agent.log` и `config/minecraft_ai_agent.log.old` импортируются в новый архив один раз. Маркер `.legacy-imported` предотвращает повторный импорт. Старые файлы не удаляются.

### 3. Кнопка COPY

В заголовке `AiLogOverlay` добавлена кнопка COPY. Нажатие копирует весь дисковый архив в хронологическом порядке: `.2`, `.1`, `latest.log`. Экспорт не зависит от вкладки Logs / Custom logs / Errors и не ограничивается экранным ring buffer в 5000 записей. После копирования панель на три секунды показывает подтверждение и количество символов.

### 4. Версия и изменённые файлы

`mod_version` повышен до 0.3.2. Изменены `AiLogClient.java`, `AiAgentLog.java`, `AiLogOverlay.java`, `AiAgentNetwork.java`, `MinecraftAiAgentClient.java`, `MinecraftAiAgent.java`, `gradle.properties`, `README.txt`; добавлен `AiLogFile.java`.

## Ограничения источников

Архив включает только то, что реально дошло до панели: live серверные Log4j events (на dedicated server подписка по-прежнему требует OP level 2) и локальную диагностику AI Agent. Это не копия полного ванильного `.minecraft/logs/latest.log`, не чтение удалённой файловой системы сервера и не автоматический сбор всех client-side logger произвольных сторонних модов. Если сторонний клиентский мод не передал событие в текущий поток панели, его запись в архив не попадёт. Архив создаётся локально на клиенте.
