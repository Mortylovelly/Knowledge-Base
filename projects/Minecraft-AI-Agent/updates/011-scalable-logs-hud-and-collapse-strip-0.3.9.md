# 011 — Масштабируемая Logs HUD и минимальная свернутая строка (0.3.9)

Дата: 2026-11-10

## Запрос

Пользователь попросил при нажатии «−» сворачивать панель до одной тонкой строки лога без кнопок и счётчиков; уменьшить рамку; сделать основное окно меньше; разрешить сильно уменьшать и увеличивать его, масштабируя при этом весь интерфейс, включая текст; удалить предметные иконки счётчиков.

## Реализация 0.3.9

Repository: https://github.com/Mortylovelly/Minecraft-AI-Agent
Branch: minecraft-1.20.1-fabric
Commit: https://github.com/Mortylovelly/Minecraft-AI-Agent/commit/d68aaafb1e73323cd1c8e1ae4d889e794c0b13e1
Minecraft 1.20.1 / Fabric / Java 17
Version: 0.3.9

### Полная панель

- Начальный фактический размер — 300 × 175 GUI px вместо 360 × 210.
- Внутренняя логическая компоновка — 360 × 210.
- Единый proportional transform применяется ко всей панели: текст логов, кнопки, вкладки, счётчики, рамка и фон масштабируются вместе.
- Resize сохраняет пропорцию 360:210; масштаб 25%–160%, верхняя граница дополнительно ограничивается viewport.
- Resize работает по горизонтальному или вертикальному движению: берётся более значимое нормализованное смещение, не требуется тянуть строго по диагонали.
- Внешняя рамка — 1 px; поле логов без дополнительной толстой внутренней рамки.
- Счётчики TOTAL/WARN/ERROR сохранены в текстовом виде. Minecraft item icons удалены. COPY и три фильтра Logs/Custom logs/Errors сохранены.

### Свернутая панель

- Нажатие «−» показывает только тонкую горизонтальную полоску с последней строкой лога.
- В свернутом состоянии не рисуются кнопки, заголовок, фильтры, счётчики и status indicators.
- Щелчок по полоске разворачивает полную панель обратно.
- COPY и close доступны в полной панели; collapsed strip намеренно не содержит кнопок.

### Мышь и свободный курсор

- G (GLFW_KEY_G) и текущее поведение free cursor не менялись.
- MouseMixin не менялся.
- Hover и обработка кликов учитывают обратное преобразование scale/animation координат.
- Drag и resize работают по экранным координатам; масштаб применяется к содержимому как единая поверхность.
