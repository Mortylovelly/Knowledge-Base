# Общая линия Fabric 1.20.1

Это справочник по ранее использовавшимся параметрам. Для конкретного проекта всегда сверять файлы репозитория.

## Известные проекты/настройки

- В проектах пользователя встречалась целевая связка Minecraft 1.20.1 + Fabric + Java 17.
- Для SkyLimitless ветка `minecraft-1.20.1-fabric` ранее была настроена так:
  - Minecraft 1.20.1
  - Yarn `1.20.1+build.10`
  - Fabric Loader `0.15.11`
  - Fabric API `0.92.11+1.20.1`
  - Fabric Loom `1.9.2`
  - Gradle `8.12`
  - Java 17
- В Fauna- ранее фиксировались:
  - Minecraft 1.20.1
  - Yarn `1.20.1+build.10`
  - Fabric Loader `0.19.5`
  - Fabric API `0.92.12+1.20.1`
  - Loom `1.17.21` (значение из последнего просмотренного gradle.properties; проверить совместимость wrapper/Gradle перед переносом)

## Важное
- Это не универсальный шаблон для всех проектов.
- Loader/API версии из одного проекта не переносить автоматически в другой.
- Для 1.20.1 не использовать Java 21, если проект и его плагины целенаправленно не настроены на неё. Известные проекты 1.20.1 пользователя используют Java 17.
- Каждый запуск Actions должен использовать тот же Java target, который ожидает `build.gradle`.
