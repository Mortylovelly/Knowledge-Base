# Archive

Здесь хранятся первичные материалы, которые помогают восстановить историю работы: экспорты переписок ChatGPT, исходные логи Minecraft, crash reports, конфигурации, заметки о тестах.

## Рекомендуемая структура

```text
archive/
├── README.md
├── chat-exports/
│   ├── README.md
│   └── <дата-экспорта>/
├── minecraft-logs/
│   └── <project>/<дата-теста>/
└── configs/
    └── <project>/<точная-версия>/
```

## Правила
- Сохранять оригиналы, не переписывать их.
- По возможности добавлять README с проектом, датой, версиями модов и обстоятельствами получения.
- Перед размещением публично проверить, что в логах и файлах нет токенов, паролей, IP-адресов/личных данных, которые владелец не хочет публиковать. Для приватного репозитория всё равно не хранить секреты.
- Большие файлы можно не добавлять в Git, а хранить отдельно и ссылаться на их место.
