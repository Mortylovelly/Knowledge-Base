# ChatGPT chat exports

Положи сюда оригинальный экспорт ChatGPT или отдельные файлы чатов, связанные с Minecraft-модами.

Рекомендуемый процесс:
1. Экспортировать данные через Settings → Data Controls → Export Data.
2. Сохранить оригинальный ZIP без изменений.
3. Добавить краткий `INDEX.md` с датой, названиями чатов и темами.
4. Не удалять оригиналы после создания Markdown-конспектов.
5. Отдельно указать, какие проекты/периоды попали в экспорт и какие отсутствуют.

В Knowledge Base пока не импортирован полный официальный экспорт: текущие описания составлены из контекста, доступного на момент создания базы.
