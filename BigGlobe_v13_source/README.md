# Big Globe v13 — исходные файлы для исправления

Сюда нужно загрузить **распакованное содержимое** архива `BigGlobe_VanillaPlus_1.20.1_v13_Fixed.zip`.

## Как загрузить

1. Скачай ZIP v13 из корня репозитория Knowledge-Base.
2. На компьютере нажми по ZIP правой кнопкой мыши → «Извлечь всё…».
3. Открой получившуюся папку. Внутри должны быть, например, `pack.mcmeta` и папка `data`.
4. В GitHub открой папку `BigGlobe_v13_source`.
5. Нажми **Add file → Upload files**.
6. Перетащи в окно загрузки содержимое распакованной папки — папку `data` и файл `pack.mcmeta` (не сам ZIP).
7. Дождись окончания загрузки и нажми **Commit changes**.

Важно: сохрани структуру папок без переименования. В итоге путь должен выглядеть так:
`BigGlobe_v13_source/data/bigglobe/...`
и файл метаданных:
`BigGlobe_v13_source/pack.mcmeta`

После загрузки напиши здесь «загрузил». Я проверю JSON и подготовлю исправленную версию. Пока ничего из исходного датапака в корне репозитория не меняй.
