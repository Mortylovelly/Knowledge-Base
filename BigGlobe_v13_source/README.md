# Big Globe — исправленная версия v14 (исходные файлы)

Эта папка содержит распакованный датапак для Minecraft 1.20.1 + Big Globe 5.3.2.

## Что изменено в v14
- Обычные пещеры больше не используют границу Deep Dark Y=-32 как нижний предел.
- Глубина стандартных типов пещер рассчитана до Y=-144 (16 блоков над нижним бедроком), с сохранением штатных ограничений глубины Big Globe для разных типов пещер.
- Большой Deep Dark-carver не возвращён; редкие скалковые элементы и диапазон Deep Dark сохранены.
- Высота Незера увеличена до 608 блоков (600 не кратно 16, поэтому для Minecraft 1.20.1 используется ближайшая допустимая высота выше 600).
- Верхний бедрок согласован с новой высотой: полный уровень Y=607, пустой предел Y=591.

## Установка
Скачай репозиторий через **Code → Download ZIP**, распакуй архив и скопируй папку `BigGlobe_v13_source` целиком в:
`saves/<название_мира>/datapacks/`

Папку можно использовать как датапак напрямую — повторно архивировать её необязательно. Внутри неё должны лежать `pack.mcmeta` и папка `data`.

После установки создай новый тестовый мир с пресетом Big Globe или проверь новые чанки. Уже созданные чанки автоматически не перестроятся.
