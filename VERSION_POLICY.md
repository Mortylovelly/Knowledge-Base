# VERSION POLICY — какую версию Minecraft мы используем

## Текущий общий стандарт

<mark></mark>
**Основная рабочая платформа сейчас: Minecraft Java Edition 1.20.1 + Fabric + Java 17.**

Это текущий стандарт для новых задач и для продолжения разработки модов, пока владелец сам явно не объявит переход на другую версию.

## Обязательные правила

1. Не переключаться на Minecraft 1.21.x, NeoForge, Forge или другую версию по собственной инициативе.
2. Не использовать другой Minecraft branch просто потому, что он называется `main`, является default branch или имеет более свежий commit.
3. При возвращении к старому моду сначала проверить его PROJECT.md, список веток и последние commits.
4. Если у мода существует несколько версий/веток и из текущего запроса, базы и истории нельзя однозначно определить целевую, **до любых изменений спросить владельца, какую версию и ветку использовать**.
5. Не угадывать target и не писать файлы в ветку, пока версия не подтверждена.
6. Если владелец прямо сказал «остаемся на 1.20.1 Fabric», использовать соответствующую ветку, если она однозначно известна.
7. Другие линии сохраняются только как архив/история/справка. Не менять их и не развивать, пока владелец отдельно не попросит.
8. Переход считается разрешённым только после прямого указания владельца с новой версией/загрузчиком. После этого обновить этот файл и проектные паспорта.

## Приоритет источников

- Прямое актуальное указание владельца в текущем разговоре.
- Настоящий VERSION_POLICY.md.
- PROJECT.md выбранного мода.
- Фактические ветки и файлы GitHub.

Если документы противоречат друг другу или ветка неясна, не выбирать самому — задать один короткий вопрос до записи кода.

## Текущая базовая связка

| Компонент | Рабочее значение |
|---|---|
| Minecraft | 1.20.1 Java Edition |
| Mod loader | Fabric |
| Java | 17 |
| Главная линия | Fabric 1.20.1 |
| Другие версии | Неактивны без явного разрешения |

Отдельные проекты могут использовать свой Fabric Loader / Fabric API / Loom / Gradle. Эти версии берутся из конкретного проекта, а не из общей таблицы.
