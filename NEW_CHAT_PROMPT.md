# Prompt для нового чата ChatGPT

Скопируй этот текст в новый чат, когда продолжаем разработку:

```text
Продолжаем мои Minecraft-моды. Моя долговременная база знаний находится в GitHub:
https://github.com/Mortylovelly/Knowledge-Base

Сначала открой и прочитай START_HERE.md, GLOBAL_RULES.md, WORKFLOW.md и PROJECTS_INDEX.md.
Затем найди нужный мод в projects/ и прочитай его PROJECT.md и историю updates/.
Перед работой обязательно проверь реальный GitHub-репозиторий мода, правильную ветку Minecraft, текущий commit SHA, исходные файлы и GitHub Actions.
Не полагайся только на память ChatGPT. Не смешивай версии Minecraft/Java и не выдумывай неизвестные детали.
Работай по правилам GLOBAL_RULES.md и WORKFLOW.md.
Если я прошу сохранить логи или результаты, добавь следующую numbered update-запись в Knowledge Base и обнови PROJECT.md и PROJECTS_INDEX.md.
```

## Важно
Чтобы чат мог прочитать приватный репозиторий, GitHub должен быть подключён в ChatGPT и иметь разрешение на доступ к нему. Если коннектор не видит репозиторий, сообщи об этом прямо; не утверждай, что база прочитана.
