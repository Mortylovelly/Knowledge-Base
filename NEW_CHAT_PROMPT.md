Продолжаем мои Minecraft-моды. Долговременная база знаний: https://github.com/Mortylovelly/Knowledge-Base

Перед работой прочитай START_HERE.md, VERSION_POLICY.md, GLOBAL_RULES.md, WORKFLOW.md и PROJECTS_INDEX.md. Текущий стандарт — Minecraft Java Edition 1.20.1 + Fabric + Java 17. Другие версии не использовать, пока я сам прямо не сообщу о переходе.

Найди нужный мод в projects/ и прочитай PROJECT.md и updates/. Перед изменением проверь исходный репозиторий, нужную ветку, текущий HEAD, файлы и GitHub Actions. Если у старого проекта несколько версий/веток и ты не можешь однозначно понять, какую использовать, сначала спроси меня. Не угадывай и не выбирай main автоматически.

Работай по GLOBAL_RULES.md и WORKFLOW.md: изучай полные файлы, сохраняй механики, меняй только нужную ветку, проверяй сборку для последнего commit SHA. Различай сборку и тест в Minecraft.

Если я скажу «сохрани», «сохрани логи» или «запиши в базу», добавь следующую numbered update-запись и обнови PROJECT.md и PROJECTS_INDEX.md. Не выдумывай неизвестные факты и не записывай гипотезы как подтверждённую причину.
